# Тестирование системного ПО OpenBMC (Лабораторные 3, 4, 5, 6, 7, 8)

Репозиторий с лабораторными работами по курсу тестирования системного ПО и интерфейсов управления серверным оборудованием OpenBMC.

- **Лабораторная работа 3:** Составление тест-плана OpenBMC (IEEE 829), тест-кейсы и раннер Варианта 8.
- **Лабораторная работа 4:** Разработка автотестов для Web UI с использованием Selenium (Page Object Model).
- **Лабораторная работа 5:** Разработка автотестов для REST API (DMTF Redfish) с использованием PyTest.
- **Лабораторная работа 6:** Сценарии нагрузочного тестирования на Locust (OpenBMC API и открытые API).
- **Лабораторная работа 7:** Настройка CI/CD конвейера с использованием Jenkins и Docker (Jenkinsfile).
- **Лабораторная работа 8:** Профилирование ПО в QEMU (сбор метрик хоста и памяти, предложения по оптимизации).

---

## ⚡ Быстрый старт

Запуск главного меню:

./run_all_labs.sh

## 🚀 Запуск лабораторных по отдельности

### Лабораторная 6: Нагрузочное тестирование (Locust)
```bash
./run_lab6.sh
```
- Меню позволяет открыть веб-интерфейс (`http://localhost:8089`) или запустить быстрый headless-тест с выводом таблицы метрик.

### Лабораторная 7: CI/CD (Jenkins в Docker)
```bash
./run_lab7.sh
```
- **Пункт 1:** Локальная симуляция конвейера Jenkins Pipeline (последовательно выполняет QEMU, PyTest, Selenium, Locust и складывает артефакты в `build_artifacts/`).
- **Пункт 2:** Развертывание Jenkins в Docker (`docker compose up -d`) на порту 8085.

### Лабораторная 8: Профилирование ПО (QEMU)
```bash
./run_lab8.sh
```
- Запуск профилировщика QEMU с замером CPU хоста и памяти до и во время нагрузки.

### Лабораторные 3, 4, 5
- **Лабораторная 3:** `./run_lab3.sh` или `python lab3_test_plan/run_lab3_variant8.py`
- **Лабораторная 4:** `python lab4_selenium_webui/openbmc_auth_tests.py --url http://127.0.0.1:8080` (для живого окна добавьте `--no-headless`)
- **Лабораторная 5:** `pytest lab5_redfish_pytest/test_redfish.py --bmc-url http://127.0.0.1:8080 -v`
